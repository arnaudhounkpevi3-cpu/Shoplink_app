1

Créer son compte et sa boutique

Le client commence par la page d’inscription. Il renseigne ses informations, choisit l’activité de sa boutique et accepte les conditions générales.

Nom, email, téléphone et mot de passe du compte client.
Nom de boutique, ville, activité et informations de base.
Si l’activité est “Autre”, le nom personnalisé est demandé.
Ouvrir l’inscription
Page inscriptionCréation compte + site
2

Passer par la page paiement

Après la création, le client passe par la page paiement. Il voit le montant, choisit le moyen de paiement et envoie l’argent au numéro ShopLink indiqué.

Le montant et le service sont affichés clairement.
Les numéros MTN et Celtiis sont visibles et copiables.
Après paiement, le client passe à la validation par capture.
Ouvrir le paiement
Page paiementValidation avant dashboard
3

Valider le paiement par capture

Après le paiement, le client uploade une capture de confirmation MTN ou Celtiis. ShopLink lit automatiquement le reçu et vérifie les informations essentielles.

La capture doit montrer le montant payé et le numéro destinataire ShopLink.
Le système détecte le code transaction pour éviter les doublons.
Si tout est correct, le compte est débloqué et le dashboard s’ouvre.
Voir la validation
Validation captureOCR du reçu
4

Gérer la boutique depuis le dashboard

Une fois le paiement validé, le client utilise le dashboard pour modifier les informations de sa boutique, ajouter des produits et suivre ses statistiques.

Ajouter, modifier ou supprimer des produits du catalogue.
Changer logo, adresse, WhatsApp, description et activité.
Voir le lien public et prévisualiser ce que les clients verront.
Se connecter au dashboard
Dashboard clientConnexion puis gestion
5

Partager le site public

Quand les produits sont publiés, le client partage son lien public. Les visiteurs peuvent voir les produits, ajouter au panier et commander via WhatsApp.

Le logo, l’adresse et les informations de boutique sont affichés.
Les produits publiés apparaissent sans doublons.
Le panier prépare une commande claire à envoyer au vendeur.
